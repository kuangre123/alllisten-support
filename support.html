常见问题

需要什么设备？

一块 Apple Watch（watchOS 26 或更新），和一台 iPhone 12 或更新的机型（iOS 26 或更新）。录音在手表上进行；转写用 iPhone 本机的 Apple 语音识别，iPhone 11 和 SE（第二代）做不了本机转写。

怎么开始录音？

在 Apple Watch 上打开 AllListen，点「开始录音」。第一次会请你允许使用麦克风，这个权限只能在手表上给。开始以后可以放下手腕，手表会在后台接着录；不方便录的场合，在手表上点暂停。

录音多久传到手机？为什么还没有逐字稿？

手表每 5 分钟切一段，iPhone 在附近时陆续传过来，收到就在本机转写。离得太远时，录音先存在手表上，回到 iPhone 附近再补传。第一次用时 iPhone 要先下载中文的识别模型，下好之前收到的录音会排队，下好以后自动转。

为什么没有日报？

生成日报需要订阅，还要选一种整理方式：iPhone 支持 Apple 智能时可以用它；不支持的话，在设置的「整理方式」里填一个自己的 API Key（比如 DeepSeek 的）。录音、转写、看逐字稿和回放都是免费的。

API Key 到哪里申请？

在设置的「整理方式」里选一家服务，下面会写到哪里申请。填好后点「测试一下」，看能不能用。用自己的 Key 时，那家服务按它自己的价格收费，和 AllListen 的订阅是两回事。

订阅包含什么？怎么取消？

订阅解锁生成日报：今天的三件事、要做的事、时间线和值得记住。订阅会自动续期，可以随时在 iPhone 的「设置 › Apple 账户 › 订阅」里取消；换了手机或重装 App 后，在付费页点「恢复购买」。

我的录音会上传吗？

不会。音频只存在你的 iPhone 上。只有你选了「自己的 API Key」时，转写出来的文字才会发给你选的那家服务，第一次发之前会先问你。

怎么删除数据？

在对话详情右上角的「⋯」里可以删除一段对话；超出保留期的录音会自动删除。删掉 App，所有数据都会一起删除。
